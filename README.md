# Resume AI Backend

## Overview

Resume AI Backend is a Spring Boot application that provides REST APIs for managing resume data and supporting AI Resume Builder functionalities.

## Features

- RESTful API architecture
- Resume data management
- User profile handling
- Backend integration support
- Scalable design

## Tech Stack

- Java
- Spring Boot
- Maven
- REST APIs

## Project Structure

src/
pom.xml
mvnw
